# 备选方案：单文件 HTML + Bento Grid 演示文稿规范

> 说明：本规范基于 Sandun（三顿）在 Linux.do 发布的《把小米379页的年报转为可视化网页，附完整提示词》整理。
> 当用户明确要求“不需要导出 PPTX / 不需要二次矢量编辑，只需要单文件 HTML、在浏览器中丝滑全屏滚动演示”时，作为非侵入式的备选方案调用。

---

## 核心 Prompt

```markdown
基于提供的源文档（例如，财务报告、分析报告、产品信息），生成一个单一、完整、可直接运行的 HTML 文件。此文件必须动态地、可视化地呈现文档中的核心发现、关键数据和结构化信息，并严格遵守以下设计和实现要求：

核心要求：
1. 单一 HTML 文件输出：
   - 最终交付物必须是一个 .html 文件，包含所有必要的 HTML 结构、CSS 样式（通过 <style> 或内联 Tailwind 类）和 JavaScript。
   - 引入 Tailwind CSS CDN 与 Lucide Icons。

视觉设计与布局：
1. 整体风格：参考 Apple 官网及发布会风格——简洁、现代，具有清晰的信息层级。
2. 布局核心：卡片式布局 (Bento Grid)
   - 主卡片 (Main Cards)：用于主要版块（执行摘要、核心价值、业务分部）。
   - 迷你卡片 / 要点卡片 (Mini-Cards)：专门用于拆分和展示包含多个要点、风险、建议的段落。
3. 色彩规范：
   - 纯黑页面背景 (#000000) 或深暗色 (#0B0F19)。
   - 品牌高亮色：自动识别品牌 VI 色（如小米橙 #FF6900、科技蓝 #00AEEF、青色 #06B6D4）。
   - 卡片背景：深灰色 (#1A1A1A 或 #222222)。
4. 演示文稿模式 (16:9 页面切换)：
   - 每页容器设为标准 16:9 比例，支持键盘方向键（Left/Right）切换。
   - 大字号排版，确保在大屏投影下清晰可读。
```
