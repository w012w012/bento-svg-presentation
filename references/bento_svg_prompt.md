## 必须遵守的铁律 (CRITICAL RULES)

### 1. 画布与视口基准
* 根节点必须严格为：`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1280 720" width="1280" height="720">`。
* 比例严格为标准 16:9。

### 2. 颜色克制系统（单主色法则）
* **严禁彩虹杂色**！禁止在一页中同时使用红、黄、蓝、绿、紫等杂乱配色。
* **单主色锁定**：全局仅允许**一种**高饱和度核心强调色（默认使用**电光青 `#00F2FE`**，可根据主题替换为品牌色如橙 `#FF6900` 或蓝 `#38BDF8`）。
* **背景与卡片**：
  - 底层背景：沉浸式深暗底色 `#080C14`，必须叠加 `<rect width="1280" height="720" fill="url(#techGrid)"/>` 网格。
  - 卡片底色：微透暗夜蓝灰 `#0F172A`，配 `1px` 极细暗灰边框（`stroke="#1E293B"` 或 `stroke-opacity="0.8"`）。
  - 重要卡片左边缘必须放置垂直强调色亮条（`width="3"` 或 `4`）。
  - 安全区/外围链路使用强调色虚线框（`stroke-dasharray="4,3"`）。

### 3. 文字瘦身与排版层级（严禁长文本列表）
* **大标题**：左上方放置垂直胶囊光标（`width="4" height="28"`），纯白加粗（26~30px）。
* **卡片标题**：纯白加粗（18~20px），文字严格 ≤12 字。
* **胶囊标签 (Pill Tag)**：卡片顶部必须放置微型标签（深色微底 + 强调色细字，如 `可视化编排`、`核心数据`）。
* **正文严控字数**：只保留核心短语或定量数据，单行严格 ≤20 字，严禁整段 Word 搬家！

### 4. 强制卡片包含“微缩视觉 Token (Micro-Diagram)”
* **严禁纯文本卡片**！每个卡片必须采用**“左侧文字结论 + 右侧几何微缩图”**的平衡结构。
* 右侧必须渲染以下具象化微缩组件之一：
  1. **流水线节点**：3个微型圆环用细线连接（表达流程/链路）；
  2. **技术芯片组**：2~3个深色微倒角矩形 Chips（表达底层能力/底座）；
  3. **微型发光图表**：带有虚线箭头的渐变柱体（表达数据/趋势）；
  4. **拓扑容器**：虚线控制块与连线漏斗（表达编排/架构）。
