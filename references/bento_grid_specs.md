# 便当网格 (Bento Grid) 布局设计规范

Bento Grid 是一种源自日式便当盒、被 Apple 广泛运用于发布会与产品页的现代化布局语言。它的本质是**用结构化的卡片容器承载非结构化信息**，是 LLM 最容易精准理解和几何控制的设计范式。

---

## 一、 几何参数基准（1280 × 720）

* **可用内容区域**：
  * 画布：`viewBox="0 0 1280 720"`
  * 外边距 (Page Margin)：上下左右保留 `40px` 安全间距
  * 顶部 Header 高度：`y = 40` 至 `y = 120`（标题高度约 `80px`，含主标题、副标题、标签）
  * 主内容区网格 (Grid Area)：`x = 40` 到 `x = 1240` (可用宽 `1200px`)；`y = 130` 到 `y = 680` (可用高 `550px`)
* **卡片留白 (Gap)**：卡片与卡片之间保持 `20px` ~ `24px` 的水平与垂直间隙。

---

## 二、 6 种经典版式模型

### 1. 单一焦点 (Single Hero Focus)
* **适用场景**：核心架构总览图、全景流程图、单项重磅突破、标语页。
* **尺寸参考**：主卡片宽 `1200px`，高 `550px`。

### 2. 两栏布局 (Two Columns)
* **50 / 50 对称型**：两张卡片并列，每张宽 `588px`，高 `550px`。
  * 适合：传统模式 vs 创新模式、现状 vs 解决方案、技术架构 vs 商业模式。
* **2/3 + 1/3 非对称型**：主卡片宽 `784px`，辅助卡片宽 `392px`。
  * 适合：左侧放置核心流程/代码编排，右侧放置关键指标与优势列表。

### 3. 三栏布局 (Three Columns)
* **三列等宽**：三张卡片并列，每张宽 `384px`，高 `550px`。
  * 适合：三阶段路线图（如 MVP → 商业化 → 生态）、三大核心支柱、三个平行业务模块。

### 4. 主次结合 (Center Stage)
* **居中大卡片 + 双侧辅助**：左右各一纵向窄卡片（宽 `280px`），居中为大卡片（宽 `600px`）。
  * 适合：居中展示核心引擎，两侧展示输入数据源与输出下游。

### 5. 顶部英雄式 (Top Hero + Bottom Grid)
* **上大下小**：
  * 顶部 Hero 卡片：宽 `1200px`，高 `250px`（承载核心结论或趋势图）。
  * 底部 2~4 个并列小卡片：高 `276px`，均匀分布于下方（承载分项论据）。

### 6. 混合网格 (Hybrid / Four-Quadrant Bento)
* **2 × 2 四象限网格**：
  * 左上 (w=588, h=263) + 右上 (w=588, h=263)
  * 左下 (w=588, h=263) + 右下 (w=588, h=263)
  * 适合：全面的企业介绍、平台核心能力、多维度指标看板。

## 三、 卡片微排版黄金法则

1. **大数字优先原则**：关键量化数据必须放大到 `font-size="36"` ~ `48`，并使用高亮色加粗显示。
2. **状态胶囊标签 (Badge)**：卡片顶部使用深灰底、浅色字的小圆角胶囊标签，作为模块分类。
3. **视觉焦点引导**：通过给核心卡片增加 `stroke` 高亮边框或微妙阴影，制造“第一眼视觉落点”。
